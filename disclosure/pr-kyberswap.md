## Why did we need it?
Uniswap v4 protocol fees are live (governance proposal 100). The protocol fee is packed per direction in `slot0.protocolFee`, but the tracker folds only the 0→1 half into `SwapFee`, which the simulator uses for both directions. Separately, on dynamic-fee pools a hook's BeforeSwap LP fee replaces the whole swap fee, dropping the protocol fee, whereas `PoolManager.swap` applies `ProtocolFeeLibrary.calculateSwapFee` to the overriding LP fee (+5 bps overquote at a 5 bp protocol fee).

## Release Note
- `ToExtra` stores slot0's packed `protocolFee` and `lpFee` as `pF` / `lpF`, only while the protocol fee is on, so other pools' Extra is unchanged.
- The simulator computes each quote's fee from the swap direction. Without `pF` (fee off, or an Extra written before this change) `SwapFee` is used as before.
- A BeforeSwap fee carrying `OVERRIDE_FEE_FLAG` (0x400000) overrides the LP fee even when it is 0; a bare non-zero fee keeps overriding as before.
- `SwapFee` itself is unchanged.
